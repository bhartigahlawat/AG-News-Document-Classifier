# README.md

## Overview

This project classifies news articles into four categories using Natural Language Processing (NLP) and Machine Learning.

## Dataset

AG News Dataset

## Technologies Used

- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Logistic Regression

## Project Workflow

1. Load the dataset
2. Preprocess the text
3. Convert text to TF-IDF vectors
4. Train a Logistic Regression model
5. Evaluate the model
